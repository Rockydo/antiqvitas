# M12 frontend art

`FrontEndBackgroundTexture` directly resolves
`loading_screen/gfx/interface/illustrations/loading_screens/frontend_bg_1.dds`.
`FrontEndGameTitle` directly resolves
`main_menu/gfx/interface/logos/eu5_logo.dds`. ANTIQVITAS overrides only those
two verified surfaces: an AD 1 Roman civic panorama and its typeset title.
The shared frontend GUI/templates, buttons, and frame textures are retained.
`tools/m12_frontend_assets.py` checks both source/master/DDS chains.
